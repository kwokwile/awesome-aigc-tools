# Maintenance roadmap / 维护路线图

Awesome AIGC Tools is maintained as a practical, vendor-neutral index. The roadmap prioritizes reliable data, clear editorial standards, and contributions that can be reviewed publicly.

Awesome AIGC Tools 将作为一个实用、中立的工具索引持续维护。路线图优先保障数据可靠、编辑标准清晰，并让所有贡献都可以公开审核。

## v1.1 — Contribution and data quality / 贡献流程与数据质量

- Add structured forms for bug reports and tool recommendations. / 增加问题反馈和工具推荐表单。
- Verify repository links, license labels, and documentation for existing entries. / 核验现有条目的仓库链接、许可证和文档。
- Extend automated tests for duplicate entries and required fields. / 扩展重复条目和必填字段的自动测试。
- Document the review and release process. / 补充审核与发布流程说明。

## Next / 后续

- Add useful projects only after their ownership, documentation, maintenance, and usage terms can be checked. / 仅在所有权、文档、维护状态和使用条款可核验后收录新项目。
- Improve bilingual descriptions through human review. / 通过人工审核持续改进中英双语说明。
- Make filtering and comparison clearer without introducing paid ranking. / 在不引入付费排名的前提下改进筛选和比较体验。

## Ongoing maintenance / 持续维护

- Review issues and pull requests in public. / 公开审核 Issue 和 Pull Request。
- Refresh public repository metadata on schedule. / 定期刷新公开仓库元数据。
- Publish releases only for meaningful, documented changes. / 仅针对有实质内容且有记录的变更发布新版本。
- Correct broken links, inaccurate summaries, and license changes promptly. / 及时修复失效链接、不准确说明和许可证变化。

See [CONTRIBUTING.md](CONTRIBUTING.md) before recommending a project or opening a pull request.

推荐项目或提交 Pull Request 前，请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)。
